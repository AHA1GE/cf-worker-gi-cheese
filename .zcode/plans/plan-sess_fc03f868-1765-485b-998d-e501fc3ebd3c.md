# Cyber Rehaul v2: Magenta/Cyan Duotone on Black

## Diagnosis (what reads "country/chill" today)
Teal-navy canvas, frosted-glass translucent cards with big rounded corners, soft blurry blobs, low-saturation grid, pastel light mode. The references (design/ folder + Dynamic.css demo) all share: **pure black canvas, flat opaque panels, saturated neon, hard angular edges, terminal/HUD furniture, constant motion**.

## Direction (confirmed)
- **Palette**: black canvas + neon cyan `#40c9ff`/`#00dbde` + magenta `#e81cff` duotone (button.md/card.md refs)
- **Glitch**: subtle — hover jitter, occasional bg glitch band, chromatic title shadow only
- **Light mode**: "cyber daylight" — near-white canvas, black text, same saturated accents, hard 2px borders + offset shadows instead of glows (glow doesn't read on white)

## Changes — almost entirely `src/index.css`, tiny template edit

### 1. Tokens (`:root`)
- Dark: canvas `hsl(240 25% 3%)` (near-pure black), near-white text, cyan/magenta accents, opaque panel `hsl(240 20% 6%)`, `--grad-neon: linear-gradient(-45deg, #e81cff, #40c9ff)`.
- Light: `hsl(210 20% 96%)` canvas, black text, darkened accent `-fg` variants for text contrast; hard offset shadow `4px 4px 0` token replaces glow.
- Bouncy easing token `--bounce: cubic-bezier(0.175, 0.885, 0.32, 1.275)` (button/card refs).
- Clip-path cut tokens: `--cut-btn` (8px cuts on two opposite corners), `--cut-card` (18px cuts), single-corner cut for badges. Clip-path replaces border-radius/corner-shape everywhere — the angular HUD language. Note: box-shadow gets clipped, so glows move to `filter: drop-shadow()` (follows the clipped shape — same trick the original theme-switcher doc used).

### 2. Panels (cards, readme, popover) — de-glass
- Opaque flat panels, 1px translucent cyan border, chamfered clip-path corners, L-shaped corner brackets via pseudo-element gradients (HUD framing).
- CSS counter generates `01`/`02`… HUD number tags on cards (pure CSS, no markup change).
- Hover: border brightens + drop-shadow glow (dark) / offset shadow deepens (light).
- Remove `backdrop-filter` glass; popover keeps `@starting-style` entry but in the new shape language; close button recolored to match (black key + cyan glow, keeps its lift/press animation).

### 3. Buttons — button.md recipe
- Black face, gradient frame `::before` (inset −2px, `--grad-neon`, same clip cuts) that **rotates 180° on hover**, blurred glow twin `::after` fading in on hover, text white→cyan, bouncy easing on transforms.
- Light mode: white face, black text, gradient frame retained, offset shadow instead of glow.

### 4. Status badges
- Angular single-corner cut; saturated per-kind hues: ok `#00ff9c`, warn `#ffd600`, error `#ff184c`, neutral gray. Dark = translucent hue bg + text glow; light = solid hue chip with black text.

### 5. Typography & small cyber furniture
- h1 keeps Silkscreen with explicit magenta/cyan chromatic shadows (subtle flicker keyframe ~every 8s).
- `h2::after` blinking `_` terminal cursor (reduced-motion guarded).
- `//` prefixes, theme switcher mechanism/ridge outline, focus rings, selection color: all recolored to the duotone.

### 6. Background
- Pure-black canvas; brighter cyan perspective grid + a magenta-cyan horizon glow line at the grid's top edge (`.bg-grid::before`); duotone blobs (cyan/magenta/deep purple, slightly stronger alpha); scanlines + sweep and subtle glitch band kept.
- Template JS: only the randomizer's palette array changes to cyber sets (cyan/magenta, swapped, purple/cyan, green/cyan) — random-per-load variety stays.

### 7. Motion (Dynamic.css-inspired entries)
- Header: fade + scale-down "materialize"; readme: slide-in from left; cards: alternating comeInLeft/comeInRight with stagger; footer: fade-up — all in the `prefers-reduced-motion: no-preference` guard, which stays the rule for every animation.
