# Theme Rehaul: Futuristic Neon / Pixel / Hack / Metal

## Current state (verified)
Two pages (`/`, `/server`) are assembled server-side from `src/html_pages/*.html` templates into `src/htmlBase.ts` (generated by `build.py`, which runs on every `wrangler dev`/`deploy`). CSS is injected at request time into a `/* STYLESHEET */` placeholder — today it's fetched live from GitHub raw `master`, falling back to a manually duplicated `src/css.ts`. Current styling: hardcoded colors, `prefers-color-scheme` media queries only, no variables, no toggle, no animations.

## Decisions (confirmed with you)
- **CSS bundled at deploy**: drop the GitHub runtime fetch; `src/index.css` becomes the single source of truth.
- **Fonts**: Silkscreen (the doc's pixel font) for Latin/headings/buttons/numbers; CJK keeps system fonts with techy styling.
- **Background**: moderate intensity — animated grid + drifting neon blobs + scanlines, randomized per load.

---

## 1. Build pipeline — single-source the CSS
- **`build.py`**: also read `src/index.css` and emit `src/css.ts` (`export const css = \`...\``, backticks escaped — same escaping as the HTML templates). Ends the manual index.css↔css.ts sync.
- **`src/index.ts`**: in `createPage()` and `createServersPage()`, remove the GitHub raw fetch and use the imported `css` directly.

## 2. New theme — rewrite `src/index.css`
- **Tokens** (doc pattern): `:root` HSL channel vars → `--theme-canvas`, `--theme-text`, `--theme-accent`, `--theme-accent-2`, glow/panel colors, all via `light-dark()`. Dark: near-black blue canvas, neon cyan primary + magenta secondary. Light: off-white metal canvas, deep teal/indigo neon. `color-scheme: var(--color-scheme)` + `:root:has(#color-scheme input:checked)` pure-CSS override fallback (works even without JS, as in the doc).
- **Metal/mechanical panels**: notched corners via `corner-shape: notch` (progressive enhancement; plain `border-radius` fallback for older browsers), brushed-metal `repeating-linear-gradient` texture, bevel inset shadows, ridge outline + neon `drop-shadow` glow, retained glass `backdrop-filter`, faint scanline overlay on cards via `::after`.
- **Buttons**: beveled pixel style, neon glow + brightness on hover, visible `:focus-visible` outlines.
- **Status badge**: colored by `[data-status="ok"|"warn"|"neutral"|"error"]` selectors, themed per light/dark (replaces hardcoded JS colors).
- **Fonts**: `@font-face` Silkscreen from a CDN (jsdelivr fontsource woff2, ~10KB — CSS is inlined so only absolute URLs work); pixel stack for headings/buttons/status, system CJK stack with letter-spacing for body.
- Responsive tweaks: cards go full-width under ~700px.

## 3. Templates — switcher, background layer, persistence
Both `main-page.html` and `server-page.html` get:
- **Blocking `<script>` in `<head>`** (~10 lines): reads `localStorage.theme`, applies `documentElement.style.colorScheme` before paint → no flash of wrong theme. Default (no/no saved value) = system.
- **`<fieldset id="color-scheme">`** in the header area (top-right): Sys / Light / Dark radios, styled per the doc (notch fieldset, ridge outline, rotating diamond radios). Labels in Chinese (系统/亮色/暗色) to match site language.
- **Change listener script**: radio change → set inline `color-scheme` + persist to `localStorage`. The `:has()` CSS covers no-JS fallback; both mechanisms agree when JS is on.
- **`<div class="bg" aria-hidden="true">`** as first body child with sub-layers: `.bg-grid`, `.bg-blob` ×3, `.bg-scanlines`, `.bg-glitch`.

Card templates: `server-page-card.html` script switches from inline `style.color/backgroundColor` to `dataset.status`; `main-page-card.html` malformed `</h2>` for `<h3>` fixed; `<spaan>` typos in `index.ts` fixed to `<span>`.

## 4. Random animated background (moderate)
- CSS keyframes: perspective grid floor slowly scrolling, 3 neon glow blobs drifting (blur + translate/scale), faint scanline sweep, subtle flicker on the grid only.
- **Per-load randomization** (small inline script): random neon palette (`--hue`/`--hue-2` from presets: cyan/magenta, lime/cyan, amber/red, violet/cyan), random blob start positions and duration jitter, random variant class (e.g. slow data-stream columns). Pure CSS-drawn, no images.
- All animation inside `@media (prefers-reduced-motion: no-preference)` — fully static under reduced motion.

## 5. Smooth element animations (doc-style)
- Entry: header / readme / cards staggered fade-and-rise (`animation-delay` via nth-child).
- Hover: card lift + glow intensification, button glow pulse, radio rotation exactly like the doc.
- Popover: open/close transitions using `@starting-style` + `allow-discrete`, backdrop fade.
- Theme change: 0.2s ease-out transitions on colors (doc pattern).

## 6. Status API theming
`serverStatus()` in `src/index.ts` returns `kind` (`ok`/`warn`/`neutral`/`error`) alongside the status text instead of `textColor`/`bgColor`; the card script sets `data-status` and CSS owns the colors per theme.

## 7. Regenerate & verify
- Run `python build.py` → regenerates `src/htmlBase.ts` and `src/css.ts`.
- Constraint: none of the new inline CSS/JS may contain a literal `${` (build.py only escapes backticks).
- `npx wrangler dev`, then browser-verify both pages: system/light/dark modes, override persistence across reloads, background variants, popover animations, reduced-motion, mobile width.
